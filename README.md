# Text Summarizer

A simple text summarization application built using Python and Hugging Face Transformers.

## Features
- Summarizes long text into shorter, meaningful content.
- Uses the DistilBART model (`sshleifer/distilbart-cnn-12-6`).
- Easy-to-use interface.

## Technologies Used
- Python
- Hugging Face Transformers
- PyTorch
- Gradio

## Installation

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python textsummary.py
```

## Model
`sshleifer/distilbart-cnn-12-6`
